# QA Automation Portfolio

Bu proje, Java kullanarak geliştirdiğim API ve UI (Web) test otomasyonu çalışmalarımı içerir.

## 🛠️ Kullanılan Teknolojiler
- **Java 21**
- **JUnit 5** (Test Framework)
- **Rest Assured** (API Testleri)
- **Playwright** (UI Testleri)
- **Maven** (Proje Yönetimi)
- **GitHub Actions** (CI/CD)

## 🚀 Testleri Çalıştırma
Tüm testleri çalıştırmak için terminale şu komutu yazın:
```bash
 mvn clean test
